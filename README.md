# ReadEase

Free offline reading app with text-to-speech.

## Features
- Library with folders, progress tracking, themes, font size, TTS
- Upload your own TXT / PDF / EPUB files
- **Download free public-domain books** from Project Gutenberg (70,000+)
- Instant offline classics (Alice, Peter Pan, Emma, Treasure Island, Sherlock)

## How to get more free books
1. Open the **Download** tab
2. Type any title or author (e.g. `Pride`, `Dracula`, `Dickens`, `Wizard of Oz`)
3. Instant offline matches appear first
4. Online results from Project Gutenberg appear below — tap **Download**
5. Books are saved offline in your Library

Search uses the free [Gutendex](https://gutendex.com/) API. Downloads go through public CORS proxies when needed.

## Run locally
Just open `index.html` in a browser (or host on GitHub Pages / any static host).

## Privacy
All books and progress stay in your browser (IndexedDB via Dexie). No accounts, no tracking.

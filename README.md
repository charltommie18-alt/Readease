# ReadEase

Free offline reading app with text-to-speech.

## Features
- Library with folders, progress tracking, themes, font size, TTS
- Upload your own TXT / PDF / EPUB files
- **Download free public-domain books** (bedtime stories, classic romance, classics)
- Instant offline classics built in

## Free books included
- **Bedtime:** Alice, Peter Pan, Wizard of Oz, fairy tales, Secret Garden, Anne of Green Gables, Christmas Carol, and more
- **Classic romance:** Pride and Prejudice, Emma, Jane Eyre, Wuthering Heights, Persuasion, etc.
- **Classics & adventure:** Sherlock, Dracula, Frankenstein, Treasure Island, Dickens, and more

## Important (copyright)
Only **public domain** books can be offered for free download (Project Gutenberg).
Modern copyrighted novels (including *Fifty Shades of Grey* and similar) **cannot** be added or distributed here.

You can still **upload your own** legally obtained EPUB/PDF/TXT files via the Library upload button.

## How to get books
1. Open the **Download** tab — popular free books appear automatically
2. Or search any free classic title/author
3. Tap **⬇️ Add** — book is saved offline in your Library

## Run
Open `index.html` in a browser or host on GitHub Pages.

## Privacy
Everything stays in your browser. No accounts, no tracking.
